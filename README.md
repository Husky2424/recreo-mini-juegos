# Recreo — Mini juegos

Una pequeña web interactiva con cuatro juegos para jugar directamente en el navegador:

- **Sopa de letras:** encuentra palabras en horizontal, vertical y diagonal.
- **Sudoku:** completa el tablero con números del 1 al 9.
- **Conecta 4:** partida local para dos jugadores.
- **Space Invaders:** mueve la nave, esquiva y dispara.

## Cómo jugar

Abre `index.html` en un navegador moderno. No requiere instalación, servidor ni dependencias externas.

En Space Invaders, usa las flechas izquierda/derecha y la barra espaciadora; en móvil, usa los botones en pantalla.
